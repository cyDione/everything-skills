# C# 架构与代码审查

按当前改动读取适用条目。本清单用于发现正确性问题和无真实职责的实现，不规定每个项目都采用相同架构。

## 实现原则

- 分开内容定义、运行时状态、规则执行与表现。优先让可独立测试的规则使用普通 C#；MonoBehaviour 负责 Unity 生命周期适配与场景装配。无需将所有模块分成独立程序集。
- 内容配置放在项目已有的 ScriptableObject、Prefab、数据表或其他真实配置入口中。运行时状态有明确所有者，不将共享配置资产作为每个单位的可变状态。
- 新增或修改的配置字段应有准确 Tooltip 或自定义 Inspector 说明，指出语义、单位、范围和默认值。玩法数值未定时标记待定，不创建臆测的平衡值。
- 不将其他引擎类型逐字替换成 Unity 类型。不能仅因框架已安装就假定项目采用全局事件总线、Singleton、ECS、依赖注入、Addressables 或联网框架。
- 在输入、配置、加载或生命周期的实际负责边界执行运行时校验。保留真实外部输入、回调重入和对象销毁所需检查；对已由内部契约保证的条件避免层层重复校验、无效重置或掩盖错误的兜底。
- 遵循当前 Scene、Prefab 与 Inspector 的资产所有权。未经授权不重新装配用户资产、升级包或引擎。保留 `.meta` 与 GUID 引用；资源移动时同步处理 `.meta`，避免无关资产重序列化。

## 正确性审查

1. 追踪入口、校验、状态提交、事件或表现、完成、取消与清理，覆盖真实失败、重复调用和回调重入。确定部分副作用如何恢复，以及提交后谁能修改状态。
2. 区分 `Awake`、`OnEnable`、`Start` 与显式初始化的责任，不依赖尚未建立的跨对象执行顺序。按真实路径检查禁用与启用、销毁、场景卸载、对象池复用和快速重试。
3. 为每个事件订阅、Input Action、协程、异步操作、临时实例及资源句柄找到所有者与生命周期。解绑时使用对应的委托；区分禁用组件、禁用 GameObject 与销毁对象的行为，并按目标 API 核实清理语义。
4. 异步结果返回时检查其是否仍属于当前战局或操作，以及 Unity 对象是否仍有效。旧操作不得解锁新操作、修改新战局或重复结算。按目标 API 核实 Unity 线程约束。
5. 检查 Enter Play Mode 设置。关闭 Domain Reload 时静态字段和事件可能跨 Play 保留；仅对真实持久状态设计重置与解绑，并验证连续进入 Play 的行为。
6. 对序列化改动检查既有 Scene、Prefab、Variant、实例 override 与 ScriptableObject 值。评估字段、类和程序集变化对资产引用及类型身份的影响；迁移特性只有经过旧资产验证才算迁移证据。
7. 检查 Runtime 与 Editor 引用、asmdef 依赖和测试程序集，确保 `UnityEditor` 不进入 Player 路径。仅在目标构建受影响时检查 IL2CPP、反射、裁剪与 AOT。
8. 输入与 UI 不应另存规则真值。按项目采用的 uGUI、UI Toolkit 或 PlayerInput 方案检查 Input Actions 生命周期、重复绑定、UI 与游戏输入竞争、导航焦点及设备切换。
9. 只有数据加载或存档任务才检查版本、稳定 ID、缺失引用与损坏输入。场景实例引用不能自动当作持久身份。性能问题应有目标规模和测量数据支持。

## 必要性审查

正确性审查后，单独检查每个新增或修改字段的生产者、消费者和寿命。缓存或快照需要时序、后续读取或测量依据；不机械删除确有依据的缓存。对赋值、`Clear` 与 `Reset` 检查真实输入、序列化覆盖和后续读取，并考虑对象池复用及带副作用的 setter。

逐个核对 guard 上游的保证及之后可能改变状态的回调、对象销毁和外部输入。确认订阅、清理、重试和 fallback 的真实责任，避免多层重复操作或静默补造无效内容。增加 Manager、接口、包装组件、定义子类、配置资产或事件总线之前，确认当前实现确实无法承担所需职责。

沿实际资产、Prefab override、初始化路径和消费者检查配置所有权；失活变体的无关字段不应阻塞当前范围。共享能力索引若缺失，按职责及行为搜索源码和资产，不推断能力不存在。检查索引登记与真实调用一致；已有资产或源码未证明的调用者，标记未接入，不虚构调用者。数据结构变动还需检查所有受影响记录与消费者。

## 审查记录

在现有任务或 Review 位置记录检查函数、资产与调用链，分别说明正确性和必要性结论、关键保证与消费者、修复复查结果、验证证据和缺口。发现项按影响排序，注明文件位置、触发场景和后果；区分静态推断与运行复现，排除纯风格偏好、重复根因及无实测依据的性能断言。结论只覆盖实际检查范围。
